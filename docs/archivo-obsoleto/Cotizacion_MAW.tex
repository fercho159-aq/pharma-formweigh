\seccion{6. Ventajas de PharmaWeigh vs. otras soluciones del mercado}

\begin{itemize}
    \item \textbf{Plataforma web moderna} --- accesible desde PC, tablet o celular, sin instalar software
    \item \textbf{Sin servidor local} --- base de datos PostgreSQL en la nube, sin licencia de Windows Server ni SQL Server
    \item \textbf{Fases de fabricación} --- cada receta se configura con múltiples fases de producción con firma por fase
    \item \textbf{Escaneo con cámara} --- además de pistola lectora, permite escanear códigos de barras con la cámara del celular
    \item \textbf{Dashboard en tiempo real} --- el supervisor ve todos los procesos activos y su progreso por fase
    \item \textbf{Soporte incluido} --- 12 meses de soporte técnico (vs. 3 meses promedio de otros proveedores)
    \item \textbf{Entrega inmediata del software} --- sin tiempos de espera prolongados como otros proveedores
\end{itemize}
