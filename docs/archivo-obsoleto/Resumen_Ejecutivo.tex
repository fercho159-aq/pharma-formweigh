\seccion{1. El Problema}

La industria farmacéutica enfrenta desafíos críticos en el control de procesos de fabricación:

\begin{itemize}
    \item \textbf{Errores de pesaje} que comprometen la calidad del producto final
    \item \textbf{Falta de trazabilidad} en el dispensado de materias primas
    \item \textbf{Procesos manuales} propensos a error humano
    \item \textbf{Cumplimiento regulatorio} (NOM, FDA 21 CFR Parte 11) que exige documentación rigurosa
    \item \textbf{Costos elevados} de soluciones existentes en el mercado (los principales proveedores cotizan por encima de \textbf{\$1,800,000 MXN} IVA incluido)
\end{itemize}

\seccion{2. Nuestra Solución: PharmaWeigh}

PharmaWeigh es un sistema web de última generación que digitaliza y controla todo el proceso de fabricación farmacéutica, desde la recepción de materias primas hasta el dispensado final con firma electrónica del supervisor.

\subseccion{Arquitectura moderna}
\begin{itemize}
    \item Plataforma 100\% web --- accesible desde PC, tablet o celular
    \item Base de datos PostgreSQL en la nube (Neon) --- sin servidores locales
    \item Desplegado en Vercel --- alta disponibilidad y escalabilidad automática
    \item Sin licencias de Windows Server ni SQL Server requeridas
\end{itemize}

\seccion{4. Funcionalidades Clave}

\subseccion{4.1 Dispensado guiado por fases}
El operario sigue un proceso paso a paso: cada fase de fabricación tiene sus propios materiales, tolerancias y validaciones. El sistema bloquea automáticamente pesos fuera de tolerancia y requiere firma electrónica del supervisor al completar cada fase.

\subseccion{4.2 Verificación por código de barras}
Cada material y lote se verifica mediante escaneo de código de barras antes de dispensar, eliminando errores de selección de materia prima. Compatible con pistola lectora o cámara del celular.

\subseccion{4.3 Trazabilidad completa}
Registro automático de todas las acciones: quién pesó, cuánto, cuándo, con qué lote, quién firmó. Generación de reportes de auditoría para cumplimiento regulatorio.

\subseccion{4.4 Control de inventario inteligente}
Gestión automática de existencias con descuento al dispensar, alertas de stock mínimo, control de fechas de caducidad, y flujo de cuarentena/aprobación/rechazo de lotes.

\subseccion{4.5 Dashboard del supervisor}
Vista en tiempo real de todos los procesos activos, fase actual de cada orden, progreso de dispensado, y acceso directo a cualquier proceso.
